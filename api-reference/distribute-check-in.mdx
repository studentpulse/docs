The source describes an operation that distributes a Check-in to students.

<Warning>
  The source endpoint summary lists `POST /checkin/distribute`. Its detailed section lists `POST /checkin/reminder`. Confirm the current path and whether the operation sends an initial distribution or a reminder before use.
</Warning>

See the [API overview](/api-reference/overview) for authentication and draft status.

## Request field

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `feedback_id` | Integer | Yes | The Check-in ID. |

## Example request body

```json
{
  "feedback_id": 123
}
```

## Example response

The source labels this response `200 OK`.

```json
{
  "status": "success"
}
```

Confirm recipient selection, delivery channels, and duplicate-send behavior with StudentPulse. The source does not define them.
