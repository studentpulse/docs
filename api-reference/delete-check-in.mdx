The source describes a delete operation using the numeric Check-in ID.

<Warning>
  This operation deletes a Check-in. The source does not define its effect on Replies, rounds, or other associated data. Confirm deletion behavior with StudentPulse before use.
</Warning>

## Endpoint

```http
DELETE https://api.studentpulse.io/v1/checkin/delete
```

See the [API overview](/api-reference/overview) for authentication and draft status.

## Request field

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `feedback_id` | Integer | Yes | The ID of the Check-in to delete. |

The source does not specify whether this field belongs in a JSON body or a query parameter. Confirm its placement before sending a request.

## Example response

The source labels this response `200 OK`.

```json
{
  "status": "success"
}
```
